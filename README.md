# FoodWise Analytics

FoodWise Analytics is an interactive food-waste dashboard that visualizes food-waste data across countries on a 3D globe. Users can select countries, compare household, retail, food-service, and total waste, and view chart-based statistics and AI-generated insights.

The dataset is based on the UNEP Food Waste Index and includes country-level waste measurements, coordinates, and flag information.

## Demo

http://food-waste-web-bucket.s3-website-ap-southeast-2.amazonaws.com/

## Tools Used

- HTML, CSS, and JavaScript
- Three.js for the interactive 3D globe
- Chart.js for data visualization
- Vite for development and production builds
- Node.js and Express for local backend development
- Amazon S3 for frontend hosting and data storage
- Amazon API Gateway HTTP API for application endpoints
- AWS Lambda for serverless data retrieval and analysis functions
- Amazon Bedrock for AI-generated food-waste analysis and recommendations
- Amazon CloudWatch for Lambda logs and monitoring
